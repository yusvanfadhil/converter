FAQ

Pertanyaan yang sering muncul.

Apakah file saya benar-benar tidak diunggah ke server?

Benar. Seluruh proses konversi berjalan di browser Anda menggunakan teknologi PDF.js dan WebAssembly. File PDF hanya ada di memori perangkat Anda dan langsung dibersihkan setelah konversi selesai. Tidak ada permintaan jaringan yang mengirim isi PDF Anda.

Berapa ukuran file maksimal yang bisa dikonversi?

Kami menetapkan batas 50 MB per file sebagai rekomendasi agar performa tetap optimal. File yang lebih besar masih bisa diproses, namun kecepatannya bergantung pada kapasitas memori perangkat Anda.

Apakah gambar di dalam PDF ikut dikonversi?

Versi saat ini fokus pada ekstraksi teks dan struktur paragraf. Gambar, tabel kompleks, dan elemen vektor akan dilewati. Teks tetap terbaca dengan baik pada PDF berbasis teks (bukan hasil scan). Untuk PDF hasil scan, dibutuhkan OCR yang belum didukung versi ini.

Browser apa yang didukung?

Aplikasi ini bekerja optimal di Chrome, Edge, Firefox, dan Safari versi terbaru. Pastikan JavaScript dan WebAssembly aktif di pengaturan browser Anda. Untuk hasil terbaik gunakan perangkat dengan RAM minimal 4 GB.
